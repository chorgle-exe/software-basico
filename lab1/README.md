# Laboratório 1 — Introdução a Compilação e Tipos de Dados

Exercícios práticos sobre compilação com GCC, tipos de dados em C e representação de valores na memória.

## Exercícios

- Compilação de programas simples
- Análise de tipos de dados (char, int, float, string)
- Visualização de valores em memória com dump
- Linking de múltiplos arquivos
